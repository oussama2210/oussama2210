## Software Engineering

<table width="100%">
  <tr>
    <td width="50%" valign="top">

**Architecture & Design**
Structuring systems around clarity, separation of concerns, and long-term maintainability rather than short-term convenience.

**API Design & Type Safety**
Building predictable, well-typed interfaces between services — designed to fail loudly and early, not silently in production.

**Scalable Systems**
Thinking in terms of load, state, and failure modes from the first line of code, not after something breaks.

</td>
    <td width="50%" valign="top">

**Backend Engineering**
Services designed around data integrity, performance, and observability.

**Automation & DX**
Removing repetitive work from the development loop so effort goes toward actual engineering problems.

**Production Mindset**
Code written to be read, deployed, monitored, and maintained — not just to run once.
